# Домашнє завдання: основи HTML

Три практичні роботи з HTML, створені та перевірені в браузері Chrome.

## Завдання 1 — «Моє хобі — програмування»
**Файл:** [task-1/index.html](task-1/index.html)

Створена HTML-сторінка з основною структурою документа, заголовками `h1` і `h2`, абзацами `p`, маркованим списком `ul`, зображенням `img` з описом `alt` і зовнішнім посиланням `a`. Додано базове CSS-оформлення.

## Завдання 2 — «Портфоліо розробника»
**Файл:** [task-2/portfolio.html](task-2/portfolio.html)

Використано семантичні теги `header`, `nav`, `main`, `section`, `footer`. Навігація з посиланнями `#about`, `#skills`, `#projects`, `#contacts` переходить до відповідних розділів. Елементи `div` і `span` застосовано для компонування та оформлення.

## Завдання 3 — «Реєстрація на онлайн-курс»
**Файл:** [task-3/registration-course.html](task-3/registration-course.html)

Форма має обов'язкові поля імені, прізвища, email та віку, вибір напряму навчання, формату (радіокнопки), додаткових інтересів (прапорці), коментар і кнопку реєстрації.

Перевірка на стороні браузера використовує `required`, `type="email"`, `min="16"`, `max="100"`. Навчальна форма не надсилає персональні дані на сервер.

### Три навмисно внесені та виправлені помилки

1. **Невідповідність `for` і `id`.** У підписі імені було `for="first"`, а в полі — `id="first-name"`. Виправлено на `for="first-name"`, щоб клік по підпису переводив фокус у поле.
2. **Відсутній `required` в Email.** Після видалення атрибута браузер пропускав незаповнене поле email. Атрибут `required` повернуто.
3. **Пропущений `</div>` після `textarea`.** У DevTools було видно, що кнопка та повідомлення потрапили всередину блоку `.field`. Закривальний тег повернуто після `textarea`.
