# Завдання 1 — Реєстрація на подію (HTML5 + Bootstrap 5 + JavaScript)

Створено адаптивну демонстраційну сторінку **AI & HealthTech Meetup 2027**. Подія вигадана для навчального завдання: реальні реєстрації не збираються.

## Файли
- [index.html](index.html) — структура HTML5 і компоненти Bootstrap 5.
- [styles.css](styles.css) — авторські стилі поверх Bootstrap.
- [script.js](script.js) — перевірка форми та повідомлення про результат.

**Сайт на GitHub Pages:** https://parashchuk23-oss.github.io/html-homework/bootstrap-task-1-event/

Bootstrap 5.3.8 завантажується з CDN. Для правильного вигляду під час відкриття локального файлу потрібен доступ до інтернету.

## Виконання вимог

1. **HTML5 і Bootstrap 5**: `<!doctype html>`, підключення Bootstrap CSS, `container`, `row`, `col-lg-*`, `form-control`, `btn`, `alert`.
2. **Подія**: заголовок, опис, дата 20.03.2027, час та онлайн-формат (демонстраційні дані).
3. **Форма**: ім'я, email, кількість учасників.
4. **Кнопка**: «Зареєструватися».
5. **JavaScript-перевірка**: ім'я не порожнє; email не порожній і коректний; кількість учасників — ціле число більше нуля.
6. **Повідомлення**: `Реєстрація успішна!` або зрозуміле повідомлення про помилку. Некоректні поля виділяються червоним.
7. **Адаптивність**: Bootstrap Grid перебудовує двоколонкову секцію у вертикальну на мобільних екранах; додаткові медіазапити в CSS.

## Як протестувати

- Відкрийте сайт, не заповнюючи поля, натисніть «Зареєструватися» → повідомлення про помилку.
- Введіть ім'я й email, але поставте кількість `0` → помилка.
- Введіть некоректну адресу, наприклад `abc` → помилка.
- Введіть ім'я, коректний email і кількість `2` → **«Реєстрація успішна!»**.
- Відкрийте Chrome DevTools і перевірте мобільну ширину 375 px.

**Важливо:** `event.preventDefault()` зупиняє відправлення форми. Без backend дані нікуди не надсилаються. Тому «Реєстрація успішна!» означає тільки успішну локальну перевірку, а не реальну реєстрацію.

## Пояснення JS

- `form.addEventListener("submit", ...)` — виконує код після натискання кнопки.
- `trim()` — не дозволяє вважати пробіли ім'ям.
- `emailInput.validity.valid` — перевіряє формат email засобами браузера.
- `Number.isInteger(count) && count > 0` — перевіряє кількість учасників.
- `classList.toggle("is-invalid", ...)` — підсвічує неправильні поля класами Bootstrap.
- `alert-success` / `alert-danger` — задає зелене або червоне повідомлення.
