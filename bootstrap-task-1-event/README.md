- [styles.css](styles.css) — авторські стилі поверх Bootstrap.

**Сайт на GitHub Pages:** https://parashchuk23-oss.github.io/html-homework/bootstrap-task-1-event/

Bootstrap 5.3.8 завантажується з CDN. Для правильного вигляду під час відкриття локального файлу потрібен доступ до інтернету.

## Виконання вимог

1. **HTML5 і Bootstrap 5**: `<!doctype html>`, підключення Bootstrap CSS, `container`, `row`, `col-lg-*`, `form-control`, `btn`, `alert`.
2. **Подія**: заголовок, опис, дата 20.03.2027, час та онлайн-формат (демонстраційні дані).
3. **Форма**: ім'я, email, кількість учасників.
4. **Кнопка**: «Зареєструватися».
5. **JavaScript-перевірка**: ім'я не порожнє; email не порожній і коректний; кількість учасників — ціле число більше нуля.
6. **Повідомлення**: `Реєстрація успішна!` або зрозуміле повідомлення про помилку. Некоректні поля виділяються червоним.
7. **Адаптивність**: Bootstrap Grid перебудовує двоколонкову секцію у вертикальну на мобільних екранах; додаткові медіазапити в CSS.

## Як протестувати

- Відкрийте сайт, не заповнюючи поля, натисніть «Зареєструватися» → повідомлення про помилку.
- Введіть ім'я й email, але поставте кількість `0` → помилка.
- Введіть некоректну адресу, наприклад `abc` → помилка.
- Введіть ім'я, коректний email і кількість `2` → **«Реєстрація успішна!»**.
- Відкрийте Chrome DevTools і перевірте мобільну ширину 375 px.

**Важливо:** `event.preventDefault()` зупиняє відправлення форми. Без backend дані нікуди не надсилаються. Тому «Реєстрація успішна!» означає тільки успішну локальну перевірку, а не реальну реєстрацію.

## Пояснення JS

- `form.addEventListener("submit", ...)` — виконує код після натискання кнопки.
- `trim()` — не дозволяє вважати пробіли ім'ям.
- `emailInput.validity.valid` — перевіряє формат email засобами браузера.
- `Number.isInteger(count) && count > 0` — перевіряє кількість учасників.
- `classList.toggle("is-invalid", ...)` — підсвічує неправильні поля класами Bootstrap.
- `alert-success` / `alert-danger` — задає зелене або червоне повідомлення.


## Завдання 2 — Калькулятор вартості квитків

На **цій самій сторінці** під формою реєстрації додано окремий калькулятор квитків. Реєстраційна форма з першого завдання продовжує працювати незалежно.

**Умови:** один квиток — **400 грн**; 1–2 квитки — без знижки; 3–4 — **10%**; 5 і більше — **20%**.

Після натискання кнопки **«Розрахувати»** JavaScript показує:
- початкову вартість;
- розмір знижки у відсотках і гривнях;
- підсумкову суму до сплати.

### Алгоритм

```javascript
const ticketPrice = 400;
const quantity = Number(ticketCountInput.value);
let discountPercent = 0;

if (quantity >= 5) {
  discountPercent = 20;
} else if (quantity >= 3) {
  discountPercent = 10;
} else {
  discountPercent = 0;
}

const originalPrice = ticketPrice * quantity;
const discountAmount = originalPrice * discountPercent / 100;
const finalPrice = originalPrice - discountAmount;
```

**Пояснення:** `const` використовується для значень, які не перепризначаються; `let` — для `discountPercent`, оскільки її значення змінюється залежно від умов. `if/else` визначає розмір знижки, арифметичні оператори `*`, `/`, `-` обчислюють ціни.

### Очікувані результати перевірки

| Квитків | Початкова вартість | Знижка | До сплати |
|---:|---:|---:|---:|
| 2 | 800 грн | 0% (0 грн) | **800 грн** |
| 3 | 1200 грн | 10% (120 грн) | **1080 грн** |
| 5 | 2000 грн | 20% (400 грн) | **1600 грн** |

Некоректне значення (`0`, від'ємне, дробове або порожнє) показує повідомлення про помилку. Кнопка калькулятора не відправляє реєстраційну форму, оскільки це окремі `form`.

**Примітка:** калькулятор не приймає оплату та не зберігає введені дані.


## Завдання 3 — Категорії квитків і промокод EVENT50

Калькулятор з другого завдання розширено **на тій самій сторінці**:
- Standard — **400 грн** за квиток;
- VIP — **800 грн** за квиток;
- 3–4 квитки — **10%** знижки;
- від 5 квитків — **20%** знижки;
- промокод **EVENT50** віднімає **50 грн** після відсоткової знижки.

Підсумок обчислюється у такому порядку:

```javascript
const originalPrice = ticketPrice * quantity;
const quantityDiscount = originalPrice * discountPercent / 100;
const afterQuantityDiscount = originalPrice - quantityDiscount;
const promoApplied = promo.trim().toUpperCase() === "EVENT50";
const promoDiscount = promoApplied ? Math.min(50, afterQuantityDiscount) : 0;
const finalPrice = Math.max(0, afterQuantityDiscount - promoDiscount);
```

`Math.max(0, ...)` не допускає від'ємного результату. Невідомий промокод не застосовується (знижка 0 грн); порожнє поле теж допустиме. Літери в промокоді не залежать від регістру.

### Сценарії перевірки

| Кількість | Категорія | Промокод | Початкова сума | Знижка за кількість | Знижка за кодом | До сплати |
|---:|---|---|---:|---:|---:|---:|
| 2 | Standard | — | 800 грн | 0 грн | 0 грн | **800 грн** |
| 3 | Standard | — | 1200 грн | 120 грн | 0 грн | **1080 грн** |
| 5 | Standard | — | 2000 грн | 400 грн | 0 грн | **1600 грн** |
| 3 | VIP | EVENT50 | 2400 грн | 240 грн | 50 грн | **2110 грн** |
| 5 | VIP | EVENT50 | 4000 грн | 800 грн | 50 грн | **3150 грн** |
| 1 | Standard | WRONG | 400 грн | 0 грн | 0 грн | **400 грн** |

Для 0, дробових, від'ємних та порожніх значень калькулятор виводить помилку й не показує застарілий результат.

Вся логіка — у `script.js`. Демонстраційна форма не приймає платежі та не зберігає введену інформацію.
