## Файли проєкту

- `index.html` — опис події, форма реєстрації та калькулятор квитків (Bootstrap 5).
- `style.css` — адаптивне оформлення сторінки.
- `script.js` — перевірка форми, розрахунок вартості та промокоду.
- `styles.css` — попередня копія CSS, збережена для історії; сторінка використовує `style.css`.

## Функціональність

**Завдання 1 — реєстрація:** ім'я, email та кількість учасників; JavaScript перевіряє обов'язкові поля, формат email і додатне ціле число учасників. Показує «Реєстрація успішна!» або повідомлення про помилку.

**Завдання 2 — калькулятор:** кількість квитків; 1–2 квитки — без знижки, 3–4 — 10%, від 5 — 20%. Кнопка «Розрахувати» показує початкову ціну, знижку та суму до сплати.

**Завдання 3 — категорії й промокод:** Standard (400 грн) і VIP (800 грн). `EVENT50` віднімає 50 грн після відсоткової знижки. Підсумкова вартість не може бути від'ємною; показано детальний розрахунок.

## Де знайти логіку в коді

1. **Перевірка реєстраційної форми:** `script.js`, обробник `form.addEventListener("submit", ...)`. Перевірки: `nameInput.value.trim()`, `emailInput.validity.valid`, `Number.isInteger(count) && count > 0`.
2. **Розрахунок ціни:** `script.js`, функція `calculateTicketOrder(quantity, category, promo)`. Ціна категорії визначається через `ticketPrices`; початкова сума — `ticketPrice * quantity`.
3. **Відсоткові знижки:** у `calculateTicketOrder` блок `if (quantity >= 5) ... else if (quantity >= 3) ... else`.
4. **Промокод:** `promo.trim().toUpperCase() === "EVENT50"`. Знижка промокоду застосовується після знижки за кількість. `Math.max(0, ...)` захищає від від'ємної суми.
