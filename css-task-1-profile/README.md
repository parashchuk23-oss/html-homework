# CSS — Завдання 1. Картка профілю

Створено навчальну картку профілю.

## Файли
- [index.html](index.html) — структура: аватар, ім'я, професія, опис і кнопка «Зв'язатися».
- [styles.css](styles.css) — оформлення картки. Підключено через `<link rel="stylesheet" href="styles.css">`.

## Як перевірити
Скачайте **обидва файли в одну папку** та відкрийте `index.html` у браузері. Кнопка «Зв'язатися» веде на відкритий GitHub-профіль, а не надсилає повідомлення.

## Вимоги
1. Аватар — кругла емблема з літерою «Я» на синьому градієнті (не особисте фото).
2. Ім'я, професія й опис — відповідні теги `h1` та `p`.
3. Кнопка «Зв'язатися» — посилання `a`, стилізоване як кнопка.
4. Окремий CSS-файл — `styles.css`.
5. Кольори й шрифти — правила `color`, `background-color`, `font-family`, `font-size`.
6. Відступи — `margin` і `padding`.
7. Заокруглення — `border-radius`.
8. Тінь — `box-shadow`.
9. Центрування — `display: flex`, `align-items: center`, `justify-content: center` у `.page`.
10. Наведення — `.contact-button:hover` змінює колір з `#2563eb` на `#1e40af`.

Картка також адаптована до вузьких екранів за допомогою `@media`, а для доступності додано `:focus-visible`.
