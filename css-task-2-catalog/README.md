# CSS — Завдання 2. Адаптивний каталог товарів

Готова навчальна сторінка **DeskNest** із сімома товарами для домашнього офісу. Використано тільки **HTML + CSS**, без JavaScript, Tailwind і backend.

## Структура

- [index.html](index.html) — семантична HTML-розмітка каталогу.
- [styles.css](styles.css) — CSS Grid, Flexbox, кольори та адаптивність.
- [images/](images/) — сім локальних SVG-ілюстрацій. Фото із зовнішніх сайтів не потрібні.

## Як виконано вимоги

| Вимога | Реалізація |
|---|---|
| Сім товарів | 7 елементів `<article class="product-card">` |
| Зображення, назва, опис, ціна, «Купити» | `img`, `h3`, `p`, `.price`, `.buy-button` |
| CSS Grid | `.product-grid { display: grid; }` |
| Flexbox | `.product-card`, `.product-body`, `.buy-row` |
| Комп'ютер — 3 колонки | `grid-template-columns: repeat(3, minmax(0, 1fr))` |
| Планшет — 2 колонки | `@media (max-width: 1023px)` |
| Телефон — 1 колонка | `@media (max-width: 600px)` |
| Зображення в межах карток | `overflow: hidden`, `width: 100%`, `object-fit: contain` |
| Кнопки по нижньому краю | `display: flex`, `flex-direction: column`, `margin-top: auto` у `.buy-row` |
| Адаптивне меню | Горизонтальне на комп'ютері, сітка 2×2 на телефоні |
| Без JS, Tailwind, backend | Лише HTML/CSS/SVG |

Кнопки «Купити» демонстраційні: ведуть до блоку контактів, **справжніх замовлень немає**. Ціни та назви товарів вигадані.

## Перевірка в Chrome DevTools

1. Відкрийте `index.html` у Chrome (для локального запуску скачайте **всю папку** разом із `styles.css` та `images`).
2. Відкрийте **DevTools**: `⌥ + ⌘ + I` на Mac.
3. Увімкніть **Device Toolbar**: `⌘ + Shift + M`.
4. Встановіть ширини **375 px**, **768 px**, **1440 px**:
   - **375 px:** 1 картка в ряд, навігація у два стовпчики.
   - **768 px:** 2 картки в ряд.
   - **1440 px:** 3 картки в ряд.
5. Переконайтеся, що сторінка не має горизонтального прокручування, зображення не виходять за межі та кнопки стоять біля нижнього краю.
6. Збережіть скриншот **1440 px** і **375 px** для здачі.

**Статус перевірки:** CSS-медіазапити реалізовано; візуальні скриншоти на трьох ширинах потрібно зробити в браузері окремо.

## Як змінювати стилі самостійно

- **Колір кнопок**: змініть `background: #16a34a` у `.buy-button` та `background: #15803d` у `.btn-success:hover`.
- **Відстань між картками**: змініть `gap: 24px` у `.product-grid`.
- **Заокруглення карток**: змініть `border-radius: 25px` у `.product-card`.
- **Перемикання на 2 колонки**: змініть `1023px` у відповідному `@media`.
- **Перемикання на 1 колонку**: змініть `600px` у відповідному `@media`.

### Пояснення Grid і Flexbox

**Grid** розподіляє картки **між собою** по колонках. **Flexbox** упорядковує **елементи всередині** кожної картки. `margin-top: auto` відсуває блок ціни й кнопки до нижнього краю навіть тоді, коли описи різної довжини.
