# JavaScript — Завдання 1. Масив об'єктів «Фільми»

У файлі [script.js](script.js) створено **масив із 8 об'єктів фільмів**, кожен має `id`, `title`, `year`, `genre`, `rating`, `watched`.

Показано звернення до властивостей через крапку та `[]`, додавання дев'ятого фільму методом `push()`, зміну `watched` з `false` на `true`, а також виведення даних через `console.log()` і `console.table()`.

**DOM і сторонні бібліотеки не використовуються.** HTML-сторінка для цього завдання не потрібна.

## Як запустити

Якщо встановлений Node.js, завантажте файл і виконайте `node script.js` у терміналі. Або вставте вміст `script.js` у консоль браузера (DevTools → Console).

## Масив vs об'єкт

- **Масив** `[]` — упорядкована колекція елементів. Отримуємо елемент за індексом: `movies[0]`; додаємо через `movies.push(...)`.
- **Об'єкт** `{}` — набір іменованих властивостей, що описують одну сутність. Отримуємо властивість: `movies[0].title`.

У цьому прикладі `movies` — масив, а кожен його елемент — об'єкт фільму. На початку 8 об'єктів, після `push()` їх стає 9.
