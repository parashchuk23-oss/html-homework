# Currency Converter — конвертер валют

Адаптивний навчальний вебзастосунок на HTML5, Bootstrap 5.3 через CDN, CSS і чистому JavaScript. Використовує `fetch()`, `async/await` та `try/catch/finally`.

**Сторінка:** https://parashchuk23-oss.github.io/html-homework/javascript-task-10-currency-converter/

## Файли

- [index.html](index.html) — форма, поля, кнопка, індикатор завантаження, результат, дата та повідомлення про помилки.
- [style.css](style.css) — адаптивні стилі.
- [script.js](script.js) — запит до API, обчислення, оновлення DOM і обробка помилок.

## Що реалізовано

1. Введення суми, вибір базової та цільової валют `USD`, `EUR`, `UAH`.
2. Кнопка «Конвертувати» та результат із валютою.
3. Дата актуальності курсу з відповіді API.
4. Індикатор завантаження: кнопка вимикається під час мережевого запиту.
5. Валідація: сума має бути числом більшим за нуль; `response.ok` перевіряється.
6. Для однакових валют результат дорівнює сумі з курсом 1, **без мережевого запиту**.
7. Помилки обробляються через `try/catch/finally`.
8. Розділено на функції `getExchangeRate()` (отримання), `calculateConversion()` (обчислення) та `updateResult()` (оновлення DOM).

## Важливе уточнення щодо Frankfurter

За умовою використовується `https://api.frankfurter.dev/v1/latest`. **У версії v1 немає UAH** (див. [список валют v1](https://api.frankfurter.dev/v1/currencies)). Тому:

- **USD ↔ EUR**: `/v1/latest?base=USD&symbols=EUR` або зі зворотними параметрами.
- **Пари з UAH**: новіший endpoint Frankfurter `/v2/rate/usd/uah` тощо. Він повертає курс `rate` і дату `date`.

Це необхідно, щоб усі три задані валюти реально працювали. Курси є довідковими, а не курсами купівлі/продажу конкретного банку. Якщо API не відповість коректно, програма показує помилку, а не підставляє число.

## Як працюють fetch і await

```js
const response = await fetch(url);
if (!response.ok) throw new Error("Помилка отримання курсу");
const data = await response.json();
```

- `fetch(url)` запускає HTTP-запит до API і повертає Promise — обіцянку майбутнього результату.
- `await` чекає завершення цієї операції **всередині async-функції**, не блокуючи весь браузер.
- `response.ok` дорівнює `true` для HTTP-статусів 200–299. Інші статуси обробляємо як помилку.
- `response.json()` читає тіло відповіді й перетворює JSON на об'єкт JavaScript.
- `try` — код, який може завершитися помилкою; `catch` — реакція на неї; `finally` — прибирає індикатор завантаження за будь-якого результату.

## Перевірка

1. `100 USD → EUR`: отримати довідковий курс та дату.
2. `100 USD → UAH` і `100 UAH → EUR`: перевірити отримання з v2.
3. `100 USD → USD`: результат 100 USD, запит не виконується.
4. `0`, від'ємна або порожня сума: повідомлення про помилку без запиту.
5. Без мережі або помилка API: повідомлення замість результату, кнопка повертається до нормального стану.
