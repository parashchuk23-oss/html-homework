# Завдання 1 — Генератор випадкових фактів (FactLab)

Адаптивна навчальна сторінка **«Цікавий факт дня»** на HTML5, Bootstrap 5.3 через CDN, CSS та JavaScript.

**Онлайн:** https://parashchuk23-oss.github.io/html-homework/javascript-task-11-random-facts/

## Структура
- [index.html](index.html) — заголовок, кнопка, текст факту, завантаження й помилка.
- [style.css](style.css) — адаптивне оформлення.
- [script.js](script.js) — отримання факту через API та оновлення DOM.

## Можливості
1. Заголовок «Цікавий факт дня».
2. Кнопка «Отримати факт».
3. Запит до API `https://uselessfacts.jsph.pl/api/v2/facts/random?language=en`.
4. Виведення факту англійською мовою на сторінці.
5. Під час запиту повідомлення **«Завантаження...»** і блокування кнопки.
6. При мережевій помилці, HTTP-помилці або некоректному JSON — зрозуміле повідомлення.
7. Нові факти можна запитувати повторними натисканнями без перезавантаження сторінки.

## Пояснення JavaScript

`factButton.addEventListener("click", getRandomFact)` запускає функцію після натискання кнопки.

```js
async function getRandomFact() {
  setLoading(true);
  try {
    const response = await fetch(API_URL);
    if (!response.ok) throw new Error("HTTP помилка");
    const data = await response.json();
    showFact(data.text);
  } catch (error) {
    showError("Не вдалося отримати факт.");
  } finally {
    setLoading(false);
  }
}
```

- **`fetch()`** — надсилає запит до зовнішнього API.
- **`async/await`** — дозволяє дочекатися відповіді асинхронно, не блокуючи сторінку.
- **`response.ok`** — перевіряє успішність HTTP-відповіді.
- **`response.json()`** — читає JSON і перетворює його на JavaScript-об'єкт.
- **`try/catch/finally`** — обробляє помилку та завжди вимикає завантаження.
- **`textContent`** — безпечно змінює текст факту.
- **`classList.toggle()`** — показує/приховує індикатор.

## Перевірка
- Відкрий сторінку й натисни «Отримати факт»: побачиш завантаження, потім текст англійською.
- Натисни повторно: буде новий запит.
- Вимкни інтернет і натисни кнопку: має з'явитися повідомлення про помилку, кнопка знову стане активною.

Не використовуються React, сервер, база даних чи LocalStorage. Факти постачає зовнішнє API, їхню достовірність для важливих цілей варто перевіряти. Код підготовлено за допомогою ChatGPT.
