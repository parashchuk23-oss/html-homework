# Movie Explorer — JavaScript, завдання 2

Консольний проєкт на основі **масиву з 8 об'єктів фільмів** із попереднього завдання. Не використовує HTML, DOM, React або сторонні бібліотеки.

## Файли та запуск

- [script.js](script.js) — масив, п'ять функцій і приклади викликів.
- Запуск у терміналі (за наявності Node.js): `node script.js`.
- Результати виводяться через `console.log()` та `console.table()`.

## П'ять функцій і методи

| Функція | Метод | Для чого |
|---|---|---|
| `getMovieTitles(movies)` | `map()` | Перетворює кожен фільм на його назву; повертає новий масив рядків |
| `getTopRatedMovies(movies, minRating)` | `filter()` | Повертає всі фільми з рейтингом **не нижче** `minRating` |
| `findMovieById(movies, id)` | `find()` | Шукає перший фільм за `id`; повертає об'єкт або `undefined` |
| `getMoviesByGenre(movies, genre)` | `filter()` | Повертає фільми із заданим жанром |
| `sortMoviesByRating(movies)` | `sort()` | Сортує за рейтингом від більшого до меншого на **копії** масиву |

### Чому сортування не змінює початковий масив?

Метод `sort()` змінює масив, на якому його викликали. Тому використано `[...movies]` — створення копії масиву (spread-синтаксис):

```js
return [...movies].sort((first, second) => second.rating - first.rating);
```

Вихідний `movies` зберігає початковий порядок `id` від 1 до 8. Це *поверхнева копія*: самі об'єкти всередині спільні, але функція їх не змінює.

### Приклади перевірки

- `getMovieTitles(movies)` → 8 назв.
- `getTopRatedMovies(movies, 8.5)` → «Інтерстеллар», «Початок», «Паразити», «Темний лицар».
- `findMovieById(movies, 3)` → «Зелена книга».
- `getMoviesByGenre(movies, "Фантастика")` → «Інтерстеллар».
- `sortMoviesByRating(movies)` → першим «Темний лицар» (9.0), останньою «Дюна» (8.0); порядок вихідного масиву не змінений.
