# JavaScript Quiz — навчальний вебзастосунок

Адаптивна вікторина з **п'ятьма питаннями про JavaScript**, трьома варіантами відповіді, **60-секундним таймером**, підрахунком балів, таблицею результатів поточного проходження та екраном результату.

**Онлайн:** https://parashchuk23-oss.github.io/html-homework/javascript-task-3-quiz/

## Структура
- [index.html](index.html) — три екрани: старт, питання, результат; Bootstrap 5.3 через CDN.
- [style.css](style.css) — оформлення, адаптивність і стани кнопок.
- [script.js](script.js) — питання, перевірка імені, логіка відповідей, таймер та результат.

Немає React, сервера чи бази даних. Ім'я та результати не зберігаються після перезавантаження. Для Bootstrap CDN потрібен інтернет.

## Як користуватися
1. Введіть ім'я з **мінімум 3 символів** і натисніть «Почати».
2. Оберіть один із трьох варіантів та натисніть «Наступне питання».
3. Правильна відповідь дає **1 бал**. Всього — **5 балів**.
4. На всі питання відведено **60 секунд**. Після завершення часу автоматично показується результат лише вже підтверджених відповідей.
5. Екран підсумків показує таблицю: ім’я, правильні відповіді, кількість питань, витрачений час (у секундах).
6. Кнопка «Спробувати ще раз» повертає на екран імені та дозволяє почати заново.

## Які DOM-елементи змінюються

| Дія | HTML-елементи | Як змінюються |
|---|---|---|
| Введення імені (`input`) | `#player-name` | `classList.remove("is-invalid")` прибирає помилку |
| Надсилання форми (`submit`) з коротким ім'ям | `#player-name` | `classList.add("is-invalid")` показує помилку |
| Натискання «Почати» (`submit`) | `#start-screen`, `#quiz-screen` | `classList` приховує старт і показує вікторину |
| Поява питання | `#question-title`, `#question-counter`, `#answers`, `#progress-bar` | `textContent` встановлює текст; JS створює три кнопки; змінюється ширина прогресу |
| Вибір відповіді (`click`) | Кнопки в `#answers` | `classList` додає `selected` обраній кнопці |
| Натискання «Наступне» (`click`) | Питання, кнопки, прогрес | Оновлюються наступним питанням; правильні відповіді збільшують `score` |
| Кожна секунда (`setInterval`) | `#timer`, `#timer-pill` | `textContent` змінює секунди; червоний стан при 10 с |
| Завершення / час вийшов | `#quiz-screen`, `#result-screen`, `#result-score`, `#result-message` | Приховує вікторину, показує результат і повідомлення, `clearInterval` зупиняє таймер |
| «Спробувати ще раз» (`click`) | Три екрани, таймер | Повертає старт, скидає значення і стани |
| Завершення тесту | `#summary-name`, `#summary-correct`, `#summary-total`, `#summary-time` | `textContent` заповнює таблицю саме поточного проходження |

## Методи для пояснення
- **`querySelector("#id")`**: знаходить DOM-елемент.
- **`textContent`**: задає або прибирає текст у DOM-елементі.
- **`classList.add/remove/toggle`**: змінює CSS-класи для показу/приховування екранів і вибору відповіді.
- **`addEventListener`**: запускає функцію, коли виникає подія `click`, `input` або `submit`.
- **`setInterval(fn, 1000)`**: викликає функцію щосекунди для відліку часу.
- **`clearInterval(timerId)`**: зупиняє відлік після завершення або перезапуску.

## Перевірка
- Ім'я з 2 символів або з пробілів → не починає тест, показує помилку.
- Ім'я з 3 символів → запускає вікторину з 60 секундами.
- Натискання «Наступне» без вибору → показує помилку, не пропускає питання.
- П'ять правильних відповідей → **5/5**.
- Якщо нічого не відповісти протягом 60 секунд → автоматично результат **0/5**.
- Після «Спробувати ще раз» таймер знову 60 секунд, рахунок 0.
- Таймер не дублюється: перед запуском нового `setInterval()` попередній інтервал зупиняється через `clearInterval(timerId)`.
- Таблиця показує витрачений час `60 - secondsLeft` у секундах; при завершенні за таймером — 60 с.
