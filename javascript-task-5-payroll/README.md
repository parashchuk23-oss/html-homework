# Завдання 1 — Калькулятор зарплати працівників

Навчальна консольна програма на чистому JavaScript. Вона обчислює зарплати чотирьох працівників за годинами та ставкою й додає бонус **10% до всієї зарплати**, якщо працівник відпрацював **понад 160 годин**.

## Файли

- [script.js](script.js) — початковий масив, обидві функції й виведення у консоль.

HTML, DOM та сторонні бібліотеки не потрібні.

## Як запустити

Якщо встановлено Node.js, у терміналі виконайте:

```bash
node script.js
```

## Пояснення коду

- `calculateSalary(hours, rate)` рахує `hours * rate`. Якщо `hours > 160`, множить всю суму на `1.10`, інакше повертає базову зарплату.
- `for...of` проходить по об'єктах масиву `employees` і виводить зарплату та позначку про бонус.
- `calculatePayroll(employees)` за допомогою `for...of` підсумовує зарплати всіх працівників, включно з бонусами.
- **160 годин** бонусу не дають, бо умова — саме **більше ніж 160**.

## Очікуваний результат

```text
Олег: 32000 грн
Марія: 36250 грн
Іван: 35640 грн (з бонусом)
Анна: 41140 грн (з бонусом)
Загальні витрати: 145030 грн
```

Перевірка: Олег 160×200=32000; Марія 145×250=36250; Іван 180×180×1.10=35640; Анна 170×220×1.10=41140; разом 145030 грн.
