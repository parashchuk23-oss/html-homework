# Завдання 2 — Каталог онлайн-курсів

Навчальна консольна програма на JavaScript. Початкові дані — масив `courses` із п'яти курсів. Результати виводяться в консоль.

## Як запустити

Потрібен Node.js. У папці проєкту виконайте:

```bash
node script.js
```

HTML, DOM, React і сторонні бібліотеки не використовуються.

## Виконання вимог

1. **`filter()`** — вибирає курси категорії `Programming`, створює новий масив.
2. **`map()`** — створює масив рядків у форматі `Назва — ціна грн`.
3. **`find()`** — знаходить курс із `id === 4`; повертає об'єкт або `undefined`.
4. **`[...courses].sort((a, b) => b.students - a.students)`** — сортує копію масиву за кількістю студентів за спаданням. Початковий `courses` не змінює порядку.
5. **`calculateAveragePrice(courses)`** — циклом `for...of` додає ціни й ділить суму на кількість курсів. Для порожнього масиву повертає 0, щоб уникнути ділення на нуль.
