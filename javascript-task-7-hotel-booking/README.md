# Завдання 3 — Система бронювання готелю

Навчальна JavaScript-програма з ES-модулями `import` / `export`. HTML-інтерфейс, сервер, база даних та сторонні бібліотеки не потрібні.

## Три основні файли

- [rooms.js](rooms.js) — початковий масив з чотирьох номерів готелю (експортує `rooms`).
- [booking.js](booking.js) — функції `getAvailableRooms()`, `findRoom(id)`, `bookRoom(id, nights)`.
- [main.js](main.js) — імпорт функцій, приклади бронювання та виведення в консоль.
- [package.json](package.json) — допоміжний файл із `"type": "module"`, щоб Node.js розумів синтаксис `import/export` у файлах `.js`.

## Як запустити

Встановіть Node.js, відкрийте термінал у цій папці й виконайте:

```bash
node main.js
```

Або `npm start`. Жодні бібліотеки встановлювати не потрібно.

## Логіка функцій

1. `getAvailableRooms()` використовує `rooms.filter(room => room.available)`. Повертає тільки доступні номери.
2. `findRoom(id)` використовує `rooms.find(room => room.id === id)`. Повертає один номер або `undefined`.
3. `bookRoom(id, nights)` спочатку перевіряє, чи існує номер і чи він доступний, потім чи кількість ночей — додатне ціле число. Обчислює `price * nights` і множить на `0.85` для бронювання на **5 і більше ночей**. Лише після успішної перевірки встановлює `available = false`.

## Очікувані результати

```text
bookRoom(1, 3): 4500 грн
bookRoom(2, 5): 10625 грн (зі знижкою 15%)
bookRoom(3, 2): Номер недоступний
Повторне бронювання id = 1: Номер недоступний
Неіснуючий id = 99: Номер з id 99 не знайдено
Некоректна кількість ночей: Помилка: кількість ночей має бути додатним цілим числом
```

Перед бронюванням доступні номери **1, 2, 4**, після — тільки **4**. Номер 4 залишається доступним, оскільки спроба забронювати 0 ночей відхилена.

**Важливо:** дані змінюються лише в пам'яті JavaScript-процесу. Після нового запуску початкові значення `available` відновлюються. Це навчальна симуляція, а не реальне бронювання.
