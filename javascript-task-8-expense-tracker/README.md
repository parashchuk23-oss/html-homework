# Завдання 1 + 3 — Expense Tracker та статистика витрат

Навчальний адаптивний вебзастосунок для обліку особистих витрат на HTML5, Bootstrap 5.3, `style.css` та `script.js`.

**Сторінка:** https://parashchuk23-oss.github.io/html-homework/javascript-task-8-expense-tracker/

## Можливості

- Форма з назвою, сумою й категорією: **Їжа**, **Транспорт**, **Покупки**, **Інше**.
- Кнопка «Додати витрату».
- Список записів із назвою, категорією, сумою та кнопкою «Видалити».
- Автоматичний підрахунок загальних витрат і кількості записів.
- Валідація: назва після видалення зайвих пробілів не порожня; сума більша за нуль. Дрібні суми округлюються до копійок.
- Автоматичне збереження в **LocalStorage** після додавання/видалення; відновлення після перезавантаження.
- Захист від пошкоджених даних у LocalStorage.
- Фільтр категорій, живий пошук за назвою, підсумки за кожною категорією та очищення всіх витрат із підтвердженням.

## Структура

- [index.html](index.html) — форма, загальна сума та список.
- [style.css](style.css) — адаптивне оформлення.
- [script.js](script.js) — стан, перевірка, збереження й відображення.

## Логіка

**State:** `expenses` — масив об'єктів `{ id, name, amount, category }`.

**Додавання:** обробник `submit` читає поля, перевіряє назву й суму, виконує `expenses.push(...)`, після чого викликає `saveExpenses()` та `renderExpenses()`.

**Видалення:** `filter()` створює новий масив без запису з вибраним `id`; далі збереження та перемальовування.

**Загальна сума:** `reduce()` проходить усі витрати й додає їх суми. Суми складаються в цілих копійках, щоб уникнути типових похибок додавання десяткових дробів.

**Відображення:** `renderExpenses()` очищає список, через `forEach()` і `createElement()` створює картки-рядки, через `textContent` заповнює дані, оновлює загальну суму та лічильник.

**LocalStorage:** `JSON.stringify(expenses)` зберігає дані під ключем `expense-tracker-expenses`; `JSON.parse()` відновлює їх при відкритті сторінки. Якщо JSON зіпсований, масив некоректний або сховище заблоковане, застосунок не припиняє роботу: використовується порожній список або робота без надійного збереження.

Дані зберігаються лише в цьому браузері, без сервера та бази даних. Не зберігайте в LocalStorage паролі, токени й інші секрети.

## Як перевірити

1. Додати «Кава», суму 85 грн, категорію «Їжа»: загальна сума — 85 грн.
2. Додати «Автобус», суму 30 грн, категорію «Транспорт»: загальна сума — 115 грн.
3. Перезавантажити сторінку: записи залишаються.
4. Видалити «Кава»: загальна сума — 30 грн.
5. Спробувати порожню назву та нульову або від'ємну суму: форма не додає запис.

HTML-інтерфейс не зберігається в LocalStorage — він створюється заново з даних масиву. Код створено за допомогою ChatGPT.

## Завдання 3 — статистика витрат

Розширено існуючий Expense Tracker; попередні функції додавання, видалення одного запису та збереження залишилися.

- **Фільтр за категоріями:** `#category-filter`, подія `change`. Пункт «Усі категорії» показує всі записи.
- **Пошук:** `#search-input`, подія `input`. Пошук за частиною назви без урахування регістру, працює одночасно з фільтром.
- **Підсумки категорій:** `filter()` + `reduce()` рахують суми для Їжі, Транспорту, Покупок та Іншого. Загальна сума та категорійні підсумки завжди враховують **усі** записи, навіть коли деякі приховані фільтром.
- **Очистити всі витрати:** кнопка `#clear-all-button` запитує підтвердження через `window.confirm()`. Лише після натискання OK масив стає порожнім, викликаються `saveExpenses()` і `renderExpenses()`. Скасування не змінює дані; для порожнього списку кнопка неактивна.
- За відсутності збігів показується повідомлення замість порожнього списку.

LocalStorage використовує той самий ключ `expense-tracker-expenses`. **Фільтри та пошук не зберігають і не видаляють витрат** — лише змінюють відображення. Додавання, видалення й повне очищення перезаписують масив у LocalStorage.

### Як перевірити

1. Додай «Кава» 85 грн (Їжа), «Квиток» 30 грн (Транспорт) і «Хліб» 40 грн (Їжа). Загальна сума — 155 грн, Їжа — 125 грн, Транспорт — 30 грн.
2. Обери «Їжа»: відображаються два записи, загальна сума лишається 155 грн.
3. Введи «кав»: показується лише «Кава».
4. Онови сторінку: витрати залишаються.
5. Натисни «Очистити всі витрати» і скасуй: записи залишаються.
6. Підтверди очищення: всі суми та список обнуляться; після перезавантаження записи не повернуться.

HTML, CSS/Bootstrap і звичайний JavaScript; без React, сервера та бази даних.
