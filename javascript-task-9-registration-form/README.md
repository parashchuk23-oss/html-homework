# Завдання 2 — Форма реєстрації з перевіркою даних

Адаптивна навчальна форма на **HTML5, Bootstrap 5.3, CSS та JavaScript**.

**Сторінка:** https://parashchuk23-oss.github.io/html-homework/javascript-task-9-registration-form/

## Файли

- [index.html](index.html) — поля, підписи, блоки помилок та повідомлення про успіх.
- [style.css](style.css) — адаптивний дизайн і стани полів.
- [script.js](script.js) — перевірка через JavaScript, без оновлення сторінки.

## Умови валідації

1. **Ім'я**: щонайменше 3 символи після `trim()`.
2. **Email**: перевірка базового формату через регулярний вираз `/^[^\\s@]+@[^\\s@]+\\.[^\\s@]+$/` (не перевіряє існування адреси).
3. **Пароль**: щонайменше 8 символів.
4. **Підтвердження**: повинно точно збігатися з паролем.
5. **Checkbox**: погодження з умовами обов'язкове.
6. **Помилки**: під відповідними полями за допомогою `textContent` і `classList`.
7. **Успіх**: після успішної перевірки з'являється **«Реєстрація успішна!»**; форма очищується.

Обробник `submit` викликає `event.preventDefault()`, тому браузер не перезавантажує сторінку. Обробники `input` показують або прибирають помилки під час редагування. При зміні пароля перевірка підтвердження повторюється.

## Як перевірити

- Ім'я «Ів» → помилка; «Іван» → правильно.
- Email «abc» → помилка; «user@example.com» → правильно.
- Пароль «1234567» → помилка; «12345678» → правильно.
- Підтвердження відрізняється → помилка.
- Немає галочки → форма не приймається.
- Усі поля правильні й галочка встановлена → повідомлення **«Реєстрація успішна!»** без перезавантаження.

## Важливо

Це **навчальна демонстрація**, а не справжня реєстрація. Не створює користувача, не виконує авторизацію, не надсилає пароль на сервер, не зберігає пароль у LocalStorage чи інших сховищах. Для тестування використовуйте вигаданий пароль, а не свій справжній.
