# Домашнє завдання — Модуль 12, Завдання 1: Smart Catalog

Новий навчальний проєкт на **Next.js 15 (App Router), React 19 та TypeScript**.

## Вимоги завдання
1. Головна сторінка з заголовком **Smart Catalog** — `src/app/page.tsx`.
2. **8 демонстраційних товарів** із назвою, ціною, категорією та статусом наявності — `src/data/products.ts`.
3. Компонент **ProductCard** — `src/components/ProductCard.tsx`.
4. Пошук за назвою — інтерактивний компонент `src/components/Catalog.tsx`.
5. Фільтр за категорією — там само, працює одночасно з пошуком.
6. Повідомлення **«Товарів не знайдено»** та кнопка скидання, якщо пошук нічого не повернув.
7. TypeScript-інтерфейс **Product** — `src/types/product.ts`.

Застосунок адаптований для телефона, планшета та комп'ютера. Серверної бази даних немає: дані зберігаються у звичайному масиві TypeScript.

## Як запустити через Cursor

Відкрий папку `nextjs-task-1-smart-catalog` у Cursor. Потрібен Node.js (рекомендовано 20+).

```bash
npm install
npm run dev
```

У браузері відкрий `http://localhost:3000` або адресу, вказану в терміналі.

Перевірка типів: `npm run typecheck`. Виробнича збірка: `npm run build`.

**Увага:** вихідні файли Next.js на GitHub не означають, що додаток автоматично працює на GitHub Pages. Для онлайн-публікації потрібне окреме розгортання на Vercel або налаштований статичний експорт.

## Як працює застосунок (простими словами)

- **Next.js** організовує сторінки та компоненти React; `page.tsx` — головна сторінка.
- **TypeScript** описує, які поля повинен мати товар: `id`, `name`, `price`, `category`, `inStock` та поля для оформлення.
- **ProductCard** — універсальний шаблон однієї картки. Інформація передається через `props`.
- **useState** запам'ятовує введений пошуковий запит і вибрану категорію.
- **filter()** відбирає товари за двома умовами. Пошук не залежить від регістру.
- При порожньому результаті React виводить повідомлення «Товарів не знайдено».

## Приклад перевірки

1. Відкрий головну сторінку: видно 8 товарів.
2. Введи `навушники`: залишиться картка навушників.
3. Вибери `Спорт`: з'являться товари спортивної категорії.
4. Введи назву, якої немає, наприклад `телевізор`: з'явиться повідомлення «Товарів не знайдено».
5. Натисни «Скинути фільтри»: відновляться всі 8 товарів.
