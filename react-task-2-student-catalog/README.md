# Завдання 2 + 3 — React: інтерактивний каталог студентів (Vite)

Навчальний адаптивний React-проєкт із чотирма картками студентів та лічильником відвідувань.

## Структура проєкту

- `index.html` — сторінка з контейнером `<div id="root"></div>`.
- `src/main.jsx` — точка входу React.
- `src/App.jsx` — масив чотирьох студентів та відображення компонентів.
- `src/components/StudentCard.jsx` — окрема картка, яка отримує **ім'я, вік і курс навчання через props**.
- `src/components/Counter.jsx` — кнопки збільшення/скидання лічильника через **useState()**.
- `src/style.css` — адаптивне оформлення.
- `vite.config.js`, `package.json` — налаштування Vite та залежності React.

## Як запустити в Cursor або терміналі

Потрібен Node.js, сумісний із Vite (для обраної версії: **20.19+ або 22.12+**).

1. Відкрий папку цього проєкту в Cursor.
2. У терміналі запусти `npm install`.
3. Запусти `npm run dev`.
4. Відкрий адресу, яку покаже термінал (зазвичай `http://localhost:5173/`).

Команди для перевірки:

```bash
npm install
npm run dev
```

Збірка для розгортання: `npm run build`. Vite створить папку `dist/`.

**Важливо:** це Vite/React-проєкт, тому файл `index.html` у папці GitHub не є готовим статичним сайтом: він посилається на JSX, який потрібно зібрати Vite. Наявне GitHub Pages-розгортання репозиторію автоматично не публікує цей React-застосунок. Для окремої публікації потрібна збірка й налаштування хостингу.

## Що зроблено

1. `StudentCard.jsx` — повторно використовуваний компонент. Через `props` отримує `name`, `age` і `course`; додатково передаються ініціали й колір аватара.
2. `App.jsx` — масив із **чотирьох** студентів. Метод `map()` створює по одному `StudentCard` для кожного.
3. `Counter.jsx` — `const [visits, setVisits] = useState(0)` з початковим нулем.
4. Кнопка «+ Додати відвідування» збільшує значення на 1, а «Скинути» повертає 0.
5. `src/style.css` адаптує сітку під телефон/планшет/комп'ютер.

## Пояснення для початківця

**Компонент** — незалежний блок інтерфейсу. `StudentCard` — одна картка; `App` збирає всю сторінку.

**Props** — дані, які батьківський компонент передає дочірньому. Наприклад:

```jsx
<StudentCard name="Олена" age={21} course="JavaScript" />
```

**useState()** — React-хук для змінної, яка впливає на інтерфейс:

```jsx
const [visits, setVisits] = useState(0);
setVisits(previous => previous + 1);
```

React автоматично оновлює значення на сторінці. Цей лічильник — спільна кількість натискань, **не окремий облік кожного студента**. Після перезавантаження він скидається: LocalStorage чи сервер не використовуються.

Код створено за допомогою ChatGPT у GitHub; Cursor AI для цього коміту не використовувався.

## Додаткове завдання 3 — інтерактивний каталог

У `src/App.jsx` додано три функції без сервера та бази даних:

1. **«Показати студентів» / «Приховати студентів».** Стан `showStudents` через `useState(true)`; натискання міняє його на протилежний. Картки умовно відображаються або приховуються.
2. **Фільтр за курсом.** Стан `selectedCourse` через `useState("all")`; список доступних курсів створюється з даних студентів за допомогою `Set`. `students.filter()` формує новий масив, не змінюючи початкові дані.
3. **Лічильник видимих студентів.** `visibleStudents.length` показує кількість карток, що зараз відображаються. Якщо список приховано, показується `0`; якщо обрано окремий курс — кількість відповідних студентів.

Стан фільтра зберігається під час приховування/повторного показу студентів. Лічильник відвідувань із другого завдання залишився без змін. Усе працює локально в React; після перезавантаження сторінки стани повертаються до початкових.

### Як перевірити завдання 3

1. За замовчуванням видно чотири картки, лічильник **«Показано: 4 з 4»**.
2. Обери `Python Basics`: залишиться одна картка, лічильник покаже **1 з 4**.
3. Натисни «Приховати студентів»: картки зникнуть, лічильник покаже **0 з 4**.
4. Натисни «Показати студентів»: знову буде одна картка вибраного курсу.
5. Обери «Усі курси»: повернуться всі чотири картки.
6. Перевір окремий `Counter`: кнопки відвідувань і «Скинути» працюють як раніше.
