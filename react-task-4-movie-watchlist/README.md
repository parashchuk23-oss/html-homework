# Завдання 4 — Movie Watchlist (React + Vite)

Адаптивний застосунок для додавання фільмів у список перегляду й позначення переглянутих.

## Функціональність

- `MovieCard.jsx` показує назву, жанр, статус і кнопку «Переглянуто». Дані отримує через **props**.
- `MovieList.jsx` за допомогою `map()` створює картки для всіх фільмів.
- Форма з назвою та жанром із перевіркою, що обидва поля заповнені.
- `useState()` зберігає масив фільмів. Новий фільм спочатку має статус «Не переглянуто».
- Кнопка «Переглянуто» змінює статус; можна натиснути «Скасувати перегляд».
- Показує загальну кількість, кількість переглянутих і непереглянутих.
- **LocalStorage** за ключем `movie-watchlist-movies-v1` зберігає додані фільми і статуси після перезавантаження.
- Під час першого відвідування показуються чотири демонстраційні фільми.

## Як запустити

У Cursor відкрий папку проєкту, а в терміналі виконай:

```bash
npm install
npm run dev
```

Відкрий адресу Vite (зазвичай `http://localhost:5173/`). Потрібен Node.js 20.19+ або 22.12+.

Для виробничої збірки виконай `npm run build`. Просте завантаження вихідного JSX на GitHub Pages не запускає Vite-застосунок: потрібна збірка й відповідне налаштування хостингу.

## LocalStorage і React

`useState(loadMovies)` завантажує збережені записи під час ініціалізації. `useEffect(..., [movies])` після змін масиву викликає `localStorage.setItem(..., JSON.stringify(movies))`. При пошкодженому сховищі використовується демонстраційний список. Якщо збереження заблоковане, показується попередження.

Дані залишаються в поточному браузері та не синхронізуються між пристроями. Усе працює без сервера й бази даних.

## Перевірка

1. Додай «Матриця» (Фантастика). Лічильник непереглянутих зросте.
2. Натисни «Переглянуто» біля нового фільму — збільшиться кількість переглянутих.
3. Натисни «Скасувати перегляд» — статус повернеться.
4. Перезавантаж сторінку — фільм та його статус залишаться.
5. Надішли форму з порожньою назвою чи жанром — з'явиться помилка.
